## 1. 项目基本信息

- 项目名称：极简倒数日
- 项目类型：移动端纯前端客户端应用（无后端、无服务器、无接口、纯本地离线可用）
- 开发技术栈：React Native + Expo + TypeScript + Zustand + AsyncStorage + Expo Notifications
- 项目定位：实习生学习型项目，主打完整流程落地、代码规范、可作为实习作品集，同时具备真实用户可用价值
- 开发周期：两周极速 MVP 版本
- 核心产品卖点：纯净无广告、无需登录、纯本地存储、轻量化、无冗余功能

## 2. 项目开发约束（最重要，AI 必须严格遵守）

### 绝对禁止开发功能（严禁自行添加）

- 禁止桌面小组件功能
- 禁止用户登录、注册、云同步、云端备份
- 禁止主题、壁纸、自定义背景、动画特效
- 禁止分类、标签、置顶、收藏、数据统计
- 禁止社交、分享、会员、内购、广告
- 禁止番茄钟、打卡、日历等无关功能

### 强制开发规则

- 所有数据仅本地存储，离线完全可用
- 代码结构分层清晰，适配作品集、可读、可维护
- 使用 TS 严格类型约束，禁止 any 泛滥
- 状态统一使用 Zustand 管理
- UI 简洁极简，够用即可，不做复杂视觉设计

## 3. 用户需求 & 产品目标

### 3.1 用户场景

学生/普通用户用于记录考试、纪念日、计划事件，查看剩余倒计时天数，到期收到手机通知提醒。

### 3.2 产品目标

- 实现完整可用的极简倒数工具
- 数据本地永久保存，重启不丢失
- 支持事件到期系统通知提醒
- 完成从 0 到 1 完整移动端客户端项目落地

## 4. 完整 MVP 功能清单（仅以下功能，不多做、不少做）

### 4.1 事件管理核心功能

- 新增倒数事件：事件名称、选择日期
- 编辑已有事件：修改名称、修改日期
- 删除事件
- 事件列表展示：展示事件名称、剩余天数/已过天数

### 4.2 时间计算规则（固定逻辑）

- 未来日期：显示「剩余 XX 天」
- 今天日期：显示「今日」
- 过去日期：显示「已过去 XX 天」
- 自动根据时间远近排序：临近事件优先置顶

### 4.3 本地数据持久化

- 所有事件数据存储在本地 AsyncStorage
- 重启 App、关闭后台，数据不丢失
- 初始化自动读取本地缓存事件列表

### 4.4 本地消息通知

- App 首次打开自动申请通知权限
- 事件到达目标日期，触发本地推送通知
- 支持后台通知触发

### 4.5 页面结构（仅 3 页）

- 首页：事件列表展示、刷新数据
- 新增事件页：表单输入、日期选择、提交
- 编辑事件页：回填数据、修改保存、删除

## 7. 非功能需求

- 性能：页面刷新不卡顿，状态更新精准可控
- 兼容性：适配主流手机屏幕
- 稳定性：无闪退、无数据丢失、无逻辑错乱
- 可维护性：代码注释清晰、分层明确、便于学习复盘

## 8. 项目交付标准（最终验收）

满足以下全部即项目完成：

- 事件增删改查全部可用
- 倒计时时间计算精准
- 本地数据持久化生效
- 本地通知正常触发
- 项目结构规范、TS 类型完整
- 可正常打包 APK、真机运行

## 9. 开发模式说明（AI 协作规则）

- AI 负责输出规范代码、样板结构、工具函数、排错优化
- 禁止 AI 私自新增功能、私自美化、私自加逻辑
- 所有代码必须可读、适合新手学习、注释清晰
- 遇到版本兼容问题优先使用 Expo 稳定 API
